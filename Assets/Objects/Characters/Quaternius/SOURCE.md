The Unity FBX is the original downloaded file. It contains the author's mannequin, skin weights, skeleton and animation takes. This is not a character model or animation generated by this project. The pack's preview and Unity setup illustration are retained as author documentation.

Unity import settings configure Humanoid, looping locomotion and in-place animation. The project prefab scales the model to approximately 1.8 m, corrects its forward direction, and overrides the original material with ivory. Reusable project assets live in `Assets/Prefabs/Player`; model and animation source remain here.
