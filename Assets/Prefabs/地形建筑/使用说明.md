# 地形建筑预制体

从这里直接拖入场景搭建关卡。所有预制体都没有展示名称文字；Hierarchy 对象名仍保留，方便查找。

- **单件模块**：120 款，按墙体、弧墙、矮墙、门洞、拱门、柱子、柱基、柱头、柱廊、横梁、山花、地板、平台、楼梯、连接件、碎石分成 16 类。
- **组合建筑**：`Temple_Courtyard` 庭院、`Terraced_Sanctuary` 台地神殿、`Processional_Avenue` 柱廊大道，共 3 套完整拼装建筑。

默认 1 Unity 单位为 1 米。模块保留三档 LOD、共享材质、静态网格碰撞，以及用于对齐的 `SnapPoints`。移动、旋转和缩放预制体根节点即可；修改单个实例外观时可以进入其子层级。

这些是静态关卡构件。网格碰撞为非凸，若要做受力移动的机关，需另外配置适合刚体的凸碰撞或组合碰撞。

原始 FBX 和 LOD 文件位于 `Assets/Objects/Environment/RuinTempleKit/`，材质与贴图分别在 `Assets/Materials/Environment/RuinTempleKit/` 和 `Assets/Textures/Environment/RuinTempleKit/`。
